Comandi Cargo

ComandoCosa fa
cargo new nomecrea un progetto (eseguibile) nella cartella nome/
cargo checkverifica che compili, senza produrre l'eseguibile (veloce)
cargo buildcompila in target/debug/ (non ottimizzato, rapido da compilare)
cargo runcompila se serve, poi esegue
cargo build --releasecompila ottimizzato in target/release/ (per la produzione)

Struttura di un progetto

nome/
├── Cargo.toml      # manifesto: [package] + [dependencies]
├── src/main.rs     # punto di ingresso: fn main()
└── target/         # output di compilazione (non va su git)

Sintassi vista finora

fn main() {                 // funzione di ingresso del programma
    let x = 5;              // immutabile: non si può riassegnare
    let mut y = 5;          // mutabile
    y = 6;
    println!("{x} e {y}");  // macro (c'è il !): stampa "5 e 6"
    println!("{}", x + y);  // segnaposto posizionale: stampa "11"
}
